# 提交清单

依据：[Kiroween 2026 官方规则](https://kiroween.devpost.com/rules)。提交前再读一次规则，以官方最新内容为准。

## 必需项

- [ ] 已在 Devpost 报名
- [ ] 选择 Resurrection 赛道
- [ ] 项目在 2026-10-30 之后新建，开发在提交期内完成
- [ ] 已披露框架、库和模板之外的既有代码或素材
- [ ] 公开的 GitHub 仓库，包含完整源码、资源和运行说明
- [ ] 仓库有开源许可证文件，并在 GitHub 的 About 区域可见
- [ ] 根目录包含 `/.kiro`，且未被 `.gitignore` 忽略
- [ ] 提供可访问的应用 URL
- [ ] 项目文字说明，包含功能介绍
- [ ] Kiro 使用说明，基于 [kiro-usage.md](kiro-usage.md)
- [ ] 演示视频小于 3 分钟，公开发布在 YouTube，并展示项目在目标设备上运行
- [ ] 视频不含未经许可的第三方商标、音乐或其他受版权保护的素材
- [ ] 第三方 SDK、API 和数据的使用符合其条款

## 项目自查

- [ ] 仓库中没有密钥、Token、私有 `.env` 或商业 WAD
- [ ] Freedoom 的 BSD 声明已保留
- [ ] GPL 引擎没有放进 MIT 仓库
- [ ] 新用户按 README 能从零跑起来
- [ ] 在线工作台用无痕窗口测试通过
- [ ] 提交材料使用英文
- [ ] 补丁、MCP 和导出物的演示内容都可以复现

## 可选奖项

- [ ] Bonus Blog Prize：在第三方平台发布文章，说明为 Kiroween 2026 而写，并提交链接
- [ ] Social Blitz Prize：帖子以 `#KiroweenHackathon26` 开头，写出最喜欢的 Kiro 功能及其如何改变开发方式
- [ ] 如果报名过 Kiroween 2025，勾选 Best Ghost of Kiroween Past
