# 工作台示例

`index.html` 是正式工作台的视觉和交互参考，用浏览器直接打开即可。它是单个 HTML 文件，内嵌了 Freedoom 0.13.0 MAP01 的数据和一个小型求值器。

## 参考什么

- **布局：** 三栏，左边是补丁，中间是地图，右边是记录。手机宽度下改为上下堆叠。
- **视觉：** “暗黑解剖台”。深色金属台面，骨白色文字；被操作选中的区域染成粉色，`RELOCATED` 用橙色并注明“请核对”，被拦下的写入用红色。颜色和字体都定义在 `<style>` 开头的 `:root` 里。
- **地图：** 用 SVG 绘制，不用 Canvas。扇区按亮度上色，血池地板单独着色，支持滚轮缩放、拖动平移和点击选中，可以切换修改前和修改后。
- **补丁面板：** 预设列表、结论（可以写入或被拒绝）、pin 结果（`expectedIndex → index` 和相似度，`RELOCATED` 时在地图上用虚线画出旧位置）、操作列表（开关、数值控件、点名字在地图上高亮）、拒绝原因和警告，以及可复制的补丁 JSON。
- **记录面板：** 字段的新旧值；被拦下时直接列出原因卡片；扇区和 Thing 的编辑器（改扇区生成带指纹的 pin 操作，改 Thing 按坐标和类型选中）；记录所在的真实文件偏移和字节，改动的字节标粉色，被拦下的标红色。

## 不要照搬什么

- **小型求值器（`NE`）：** 只是为了让示例离线可用。它在 MAP01 上与真实引擎对比过 1500 组随机编辑，结果一致，但只实现了界面能改的那部分规则。正式版必须调用 `@necrohex/core` 和 `@necrohex/adapter-wad`，不能保留第二套规则。
- **内嵌数据：** 正式版应在浏览器里解析内置的 Freedoom 样本和用户导入的 WAD，不能写死 JSON。
- **缺少的功能：** 示例只覆盖 MAP01，没有导入补丁和导出 PWAD，也只在桌面宽度检查过。
